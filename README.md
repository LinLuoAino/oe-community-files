# OE community public file channel

This repository stores files in GitHub Release assets for the OE community app.

- Files in this repository and its Releases are public and can be downloaded without an OE account.
- Uploading a file here does not certify its safety or compatibility. Check its source and SHA-256 before use.
- Assets may be removed after the community's replica retention period. The app retrieves another verified copy when needed.
- Community source code, credentials and private account data do not belong in this repository.
